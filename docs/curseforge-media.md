# CurseForge screenshots and video

Edwin captures in game; Claude crops, captions (EN + FR) and edits.
Never automate input in the game client: playing the character for him is botting under Blizzard's terms.

## Before capturing

- Bags nearly full, 3 or more finished quests in the log, at least one holding quest items.
- One quest item in the bags that belongs to no quest in the log.
- UI scale normal, chat cleared (`/clear` or scroll it empty), no private names in party/guild chat.
- In-game screenshot key: Print Screen. Files land in `_forever_/Screenshots`.

## Shot list (6 screenshots)

1. The DropOff window open: finished quests, slots freed per quest, quickest first.
2. The numbered trip of the current quest: flight master, flight, zeppelin or boat, walk, time estimate.
3. The world map with the trip drawn as a line.
4. The minimap with the yellow line and the arrow (TomTom or the game pin).
5. The "items with no quest" list showing the orphan quest item.
6. The chat line when bags are nearly full.

## Video (30 to 45 s)

- Record with `Cmd+Shift+5`, "Record Selected Portion" on the game window, 1080p.
- One take: open `/dropoff`, read the list, follow the trip to one hand-in, turn it in, the window moves to the next quest.
- Raw file anywhere; Claude cuts it with ffmpeg and adds captions, or builds a Remotion edit from the six screenshots.
